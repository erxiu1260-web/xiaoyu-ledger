# 小鱼的记账本

一个温柔的粉色记账本网页，最初是为小鱼定制的，带一点手账风的小装饰。打开网页就能用，不用安装，不用注册。

## 功能

- **记账**：支出和收入，分类、备注、日期、心情标签
- **月度预算**：进度条，并算出「之后每天还能花多少」
- **日历视图**：每天的花费用颜色深浅表示，点一天就能看到当天的明细，也可以直接在那天补记一笔
- **统计**
  - 本月数据：总支出、和上月比、日均、最大一笔、花得最多的分类、零花费日
  - 每日支出折线图（带日均线）
  - 累计支出与预算节奏折线图
  - 分类占比环形图和条形图
  - 周几最爱花钱柱状图
  - 全年收支走势折线图
- **明细**：按天列出，可以删除
- 深色模式跟随系统

## 每个人都有自己的版本

- 同一个网址，每个人打开都是**自己的账本**。数据只存在自己设备的浏览器里，别人看不到。
- 点右上角 ⚙ 可以改**昵称**（标题会变成「你的昵称的记账本」）、**主题色**（樱花粉、蜜桃、薰衣草、薄荷、晴空）和**每月预算**。
- 换手机或换浏览器之前，在设置里点「导出备份文件」，到新设备上再「从备份导入」。

## 版本

每次更新都会新建一个编号文件夹，旧版本不会删除：

| 版本 | 地址 | 内容 |
|---|---|---|
| v1 | `/v1/` | 第一版：粉色手账风 |
| v2 | `/v2/` | 日历、折线图、统计图，可改昵称和主题色 |

首页会列出所有版本，并有「打开最新版」按钮。账本数据在各版本之间通用。

## 文件

- `src/app.html`：当前正在开发的源码
- `v1/`、`v2/` …：已发布的各个版本（只增不改）
- `versions.json`：版本列表，首页从这里读取
- `release.ps1`：发布新版本，例如 `.\release.ps1 -Note "这一版改了什么"`，编号自动加一，已存在的编号不会被覆盖
